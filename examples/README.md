# 示例

5 张照片，5 位作家，5 种「看的方式」。每条都附了**文心**（那句不写出来的话）和**材料怎么碰**，方便对照它为什么这样写。

| 02 | 小林一茶 | 都空着 | 我也空着手，跟它一样 | [02-小林一茶-都空着.md](02-小林一茶-都空着.md) |
| 03 | 村上春树 | 以为有出口 | 灯在往前引，可那头什么也没有 | [03-村上春树-以为有出口.md](03-村上春树-以为有出口.md) |
| 04 | 鲁迅 | 隔着一堵墙 | 窗是给外头的人看的，里头的人不看 | [04-鲁迅-隔着一堵墙.md](04-鲁迅-隔着一堵墙.md) |
| 05 | 王小波 | 中间空着 | 灯只照它负责的那一块，中间归没人管 | [05-王小波-中间空着.md](05-王小波-中间空着.md) |

## 这几条是怎么挑的

不是挑「最漂亮」的，是挑**最能看出差别**的：

- **迟子建**：她的碰法是替人打算——不写楼多大、人多小，只惦记天黑前能不能认出自家窗。
- **小林一茶**：先跟空盘子说话，最后把自己也算进穷日子里（「我兜里什么也没有」）。
- **村上春树**：给「我」一个期待（以为有出口），再让灯把它打掉；疼的地方在「以为」，不在「不想知道」。
- **鲁迅**：把「我」放在墙外——被隔住的那一个；末句对仗，冷里有不平，不抒情。
- **王小波**：站进那圈灯的中间，推演出自由要付的代价——管不着的地方，也什么都没有。
