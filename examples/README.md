## 这几条是怎么挑的

不是挑「最漂亮」的，是挑**最能看出差别**的：

- **村上春树**：把「我」放进屋里，先向别人的窗认领同类，再关灯——动作收尾，不是感慨收尾。
- **太宰治**：喊到一半先自我否定，破折号后面才是真话；自我否定是他的签名，不是自怜。
- **鲁迅**：不替画里人喊，只把「都张着嘴」和「举着灯照」摆在一起，末句发问——问的是「喊给谁听」，不是「好惨」。
- **王小波**：把「软」当规则来推，最后落一句大白话的规矩——理趣落在生活秩序上，不落在玄学上。
- **余华**：一句一个动作，末句只剩否定；不写气氛，气氛自己出来。
- **小林一茶**：让「看」本身成为题记的动作，把错觉认下来就停；短、实、不解释。
- **迟子建**：给色块一个带体温的动作（捂着），再让走过的人把它留下——旁观是贴着看，不是监控探头。
- **汪曾祺**：用「印画的活儿」看它，末句是手艺评语——不解释艺术，只谈工序。
