# 07｜迟子建｜替墙捂着

**画作**：Mark Rothko 色域绘画（原作信息未标注），示例依据美术馆展厅实景照片

> 示例只看画，不写画家、笔触、流派、名气与创作背景——把它当一张照片。

**主旨：替墙捂着**

> 一面白墙，当中一大块橙红，上头一条红，中间一条黄，底下又深回去。
> 这点暖挂在这么白的墙上，像一块火，捂在谁的手心里，不敢松。
> 人从底下走过去，鞋跟抬起——她走了，火还得替这面墙捂着。

| 项 | 内容 |
|---|---|
| 文心（不写出来的那句） | 这点暖是替这面白墙捂着的；人走了，它还得捂。 |
| 材料与碰撞 | 一大块橙红与红黄条 × 白墙、走过的人。先给色块一个「捂着」的动作（比喻要带体温），再让走过的人把这点暖留在墙上。 |
| 档位 / 站位 | B 物×物／不进场（照顾型） |
| 校验 | PASS｜主旨 4/7 ｜ 题记 75/99 字，3 行 / 3 句 |
| 不写什么 | 不写罗斯科、不写「色域」「冥想」；不写「温暖」「孤独」；不把画说成宗教。 |
