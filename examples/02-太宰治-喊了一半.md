# 02｜太宰治｜喊了一半

**画作**：Edvard Munch《呐喊》（The Scream），1893，挪威国家博物馆（Nasjonalmuseet）

> 示例只看画，不写画家、笔触、流派、名气与创作背景——把它当一张照片。

**主旨：喊了一半**

> 我两手捂着脸，嘴张着，喊到一半又咽回去。
> 后面那两个人还在往前走，谁也没停。喊出来也没人应——我这人，本来就不该喊的。

| 项 | 内容 |
|---|---|
| 文心（不写出来的那句） | 喊出来也没人应——那还是咽回去，本来就不该喊。 |
| 材料与碰撞 | 捂脸张嘴的「我」× 后面两个继续往前走的人。喊到一半先自我否定，再补一句更狠的（我这人，本来就不该喊）；破折号是这口气的入口，不是装饰。 |
| 档位 / 站位 | A 人×物／进场（我就是画里那个人） |
| 校验 | PASS｜主旨 4/7 ｜ 题记 49/99 字，2 行 / 3 句（第二行两句） |
| 不写什么 | 不提画题《呐喊》、不写「尖叫」「绝望」；不写那两个人是谁、为什么走。 |
