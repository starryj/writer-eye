# 规则与边界

## 一、字数口径

- 主旨：3–7 字（校验器只卡上限 7，下限 3 自查）
- 题记：≤99 字
- **均不含标点**：标点照常写全角，只是不计入字数
- **计数单位**：汉字、数字、英文字母各计 1（「16」= 2 字）；标点、空格、换行不计
- **「行」= 物理换行**：题记 1–5 个由换行符（\n）分开的段落，一行最多两句。写成一大段、靠分号或逗号断句，按 1 行判
- **句**：以句号、问号、叹号计。1–5 句都行，一句也成立
- **行 × 句 × 末句标点是作家的签名，不是格式**：八位各有一个默认区间（见各档案「节奏签名」），照片气口不同可以改，改了在自评里记一句
- 校验命令：`node scripts/check_caption.mjs "<主旨>" "<题记>"`

## 二、八条红线

1. **不署作家名**：主旨与题记正文里不出现作家姓名，也不出现「像××写的」。「笔调：<作家>」那一行是唯一例外。
2. **不搬原文**：不抄、不拼接、不改写名句。只借「看的方式」。
3. **不编造**：只写照片里看得见的东西。人名、地名、事件、声音、时间一律不补。写「我」的动作也只许延长画面里已有的那一个（界线见第四节）。
4. **不越过事实抒情**：宁可平，不许为了味道写不存在的声音、颜色、光线、天气。
5. **不猜身份**：人像不写「她是一位…」「他一定…」；他人的照片同样适用。
6. **不消费作家生平**：不把他的病、死、绯闻写进题记（尤其太宰治、鲁迅）。
7. **不共用模板**：不复用某位作家的招牌句式；**也不许把同一套「材料—情绪」换个署名再用**。检验法：把署名换成另一位作家，句子如果照样成立，就是共用模板，作废重写。
8. **不写情绪词**：荒凉、孤独、温暖、惆怅、寂寥这类词，一出现就是替读者下结论。情绪靠落差碰出来。

## 三、落笔前五问

按顺序问，卡住哪一步就回到哪一步：

1. **文心是什么？**——一句不写进题记的话。定不出来＝还没看见。
2. **材料是他的吗？**——物件、关系、情绪来源，必须出自该作家档案「〇、材料宇宙」。
3. **碰在哪儿？**——画面里哪两样东西可以撞出落差（大×小、近×远、动×静、人×规矩）。
4. **碰过人没有？**——「我」有没有真跟那样东西交手（见第四节）。只站在旁边看它＝景物说明。
5. **口气对吗？**——句长、虚词、停顿，按该作家第 4 项各自的尺子，不用统一标准。

## 四、互动与不编造的边界

2026-11-13 加。只写「物体＋氛围」会停在景物说明；再深一档，是写人跟那样东西的来往。

**三件事按顺序来：**

1. **物体立一条规矩**——它只照自己脚下一块／玻璃把两边都收进去／猫不看我。
2. **我按人的常理去办**——伸手碰一下／往旁边站一步／举着相机等。
3. **规矩把我弹回来**——它只晃两下／什么也没照着我／我拍的其实是自己。

**荒谬＝人的常理在这条规矩前失效；情绪＝被弹回来的那一下。** 不要直接写情绪词。

**两档怎么选（2026-11-13 加）**

- **A 档｜人×物（默认）**：题记里有人跟物打交道——「我」的动作，或画面里的人的动作，或替人打算的那一句。
- **B 档｜物×物（兜底）**：只在三种情况用——照片里没有可交涉的人或物（纯山、纯水、纯墙）；这一位本来就不进场（档案「互动」行写了**站位**）；委托方明确要「安静版」。
- **B 档的合格线**：仍要碰一下（大×小、近×远、动×静），只是不写人的动作。罗列不碰＝景物说明，不合格。
- **档位 ≠ 站位**：档位管「这条碰的是人×物还是物×物」，站位管「我进不进场」。进场：一茶、村上、太宰、王小波；不进场：鲁迅、迟子建、汪曾祺、余华。
- **不要按口味选**：先看照片有没有可交涉的人或物，再看这一位进不进场；两个都不成立才降到 B 档。

**可以做：**

- 延长画面里已有的动作：举着的相机可以按下去，蹲着可以一直不动，伸出去的手可以碰到画里那盏灯。
- 立规矩、写「我」的念头、判断、认输，都可以。
- 「我」＝拍照的人，在原地那点小动作都算数。

**不可以做（做了就是编造）：**

- 添道具：冰啤酒、冰箱、沙发、椅子、烟。
- 添别人：谁在黑里摔了跤、屋里睡着的人、楼下路过的人。
- 添声音、天气、温度：压缩机嗡一声、外面下雨、灯是温的。
- 让「我」跑出画面：走过去关灯、回家、找人来修。

> 两条来路要分清：**从画面长出来的动作**可以写；**为了让句子好看而加的东西**不能写。外评建议里“冰啤酒罐不冒汗”“谁在黑里摔了跤”都属于后者，不能照抄。

## 五、末句与行数：收尾是最后一道署名

**末句按人定，不按字数定。** 每位作家档案「〇、材料宇宙 · 末句」一栏写着他该怎么收：

| 作家 | 末句收法 |
|---|---|
| 小林一茶 | 物各得其所的认（草也就这么长），或一句季语；自嘲只许轻带，且必须落在物上 |
| 村上春树 | 一个念头（想、猜、不明白） |
| 鲁迅 | 反问或反话，宁可短 |
| 迟子建 | 家常打算或惦记（该……／等着吧） |
| 汪曾祺 | 手艺评语，或轻轻荡开 |
| 余华 | 一个动作，或一句否定 |
| 太宰治 | 自我否定或辩解 |
| 王小波 | 大白话理趣，越短越好 |

- 八个人都拿 5–8 字大白话收尾，就是模具，不是口气。
- **行数不必齐一**：1–5 行都合法，三行三句不是默认。俳句作家可以两行甚至一行，长句作家允许三到四句；每张都正好三行＝速写模具。**先看照片的气口，再定这位作家的签名**（各档案第 4 节「节奏签名」）。
- 同一批里题材别连撞（三张全自然小物、三张全空景、三张全公路）。撞了换照片，不要靠换句子遮掩。

**无主体画面（抽象、色块、纹理）**：按 SKILL.md 3.5 走「久看生象」——放下「这是什么」→ 让时间进场（退两步、看久了）→ 让它长成一件自然物 → 收在一句「认」上。**不许用「我也没理清」这类自嘲收**：那不是抽象画的出口，是拿画说自己。

## 六、语言质感（2026-11-14 加）

**末句对型只是最后一道署名，前面的句子也带口音。** 收尾对了、通篇是记录腔，仍然不像。三种实测的「对了但不像」（都出自 2026-11-13 名画试写）：

| 现象 | 例 | 病 |
|---|---|---|
| 自嘲成瘾 | 一茶写波洛克：「我这辈子，也没理清过什么。」 | 自嘲压过物，草木不见了；拿画说自己 |
| 探头记录 | 迟子建写罗斯科：「等她走过去了，那块橙红还得在那儿挂着呢。」 | 画面准，一个比喻都没有；她的旁观是贴着、有体温的 |
| 短成报坐标 | 鲁迅写格尔尼卡：「牛回过头来，马仰着头，嘴都张着。」 | 短在「切」，不在「看」；准确但没有判断 |

三条病根是同一个：**把作家当成收尾模板，没当成说话的质地。**

检验法：把这一条读给熟悉这几位的人听，不署名，他认不认得出。认不出，改质地，不要改节奏。

## 七、软提示（仅供参考，不作判据）

2026-11-13 起，本 skill **没有硬节奏规则**。脚本输出分三级：FAIL 硬规则（必须改）／WARN 真问题（主旨重复、同字开头、分号串事实、末句写情绪词）／TIP 节奏提示。**TIP 永不判错**，加 --strict 才把 WARN 升 FAIL。下面这些只作体检：

- 各行长度太均匀、全篇没有短句、末句太长、每句都以句号收尾——只是体检。「俳句本来就该匀，村上本来就长」，对不同的作家意义不同。
- 多张时，同一招（同一种开头或收尾）别连着用两次。
- 题记别把主旨再说一遍。
- 行内别用分号串三个事实。

## 八、情绪四查（缺一条就重写）

1. **一眼有情绪**：读完第一反应是「啊，原来这么美／这么荒凉／这么好笑」吗？只觉得「写得准」→ 重写。
2. **文心在里面**：那句没说出口的话，读者**感得到**，不是读得到。
3. **有人卡着**：有一个具体的人（或猫、物）卡在「该怎样却没怎样」的处境里，「我」站在他旁边，不是站在画面外。缺这一层，句子再准也浅。
4. **换署名不成立**：把「笔调：××」换成另一位作家，句子就立不住。

## 九、自检清单（每次输出前，以此为准）

- [ ] 主旨 3–7 字，题记 ≤99 字（均不含标点）
- [ ] 题记 1–5 个换行段、1–5 句，一行最多两句；行句数符合这一位的节奏签名（不合也没错，但要说得出为什么）
- [ ] 情绪四查都过
- [ ] **末句对型**：末句是这一位该有的收法（见第五节），不是通用短句一叹
- [ ] **碰过了**：「我」跟画面里那样东西交过手，不是站在旁边把它描述一遍
- [ ] **三张不撞车**：同一作家／同一批的题材没连撞；行数没有全部齐一
- [ ] 主旨与题记正文没有作家姓名、没有「像××写的」；没有原文
- [ ] 每一句都能在照片里找到对应；没有人名、地名、声音、时间的编造
- [ ] 没有写出来的情绪词；没有替人抒情
- [ ] 主旨与题记不重复
- [ ] 材料出自该作家「〇、材料宇宙」，不是从别处借来的
- [ ] 人像：不猜身份、不写关系、不写心理活动
- [ ] **语言质感对型**：整句质地是这一位的（一茶的留白与物／迟子建那处「捂热的」比喻／鲁迅短到发冷），不只是末句对型
- [ ] **没借标题的力**：画题、文件名会替句子出力；把标题拿掉，这句还站得住吗

## 十一、失败样例（都是真的）

| 失败 | 原句 | 哪里错 |
|---|---|---|
| 风景速写 | 「白墙红顶，草全往一边倒」署名村上 | 村上的疏离不从荒山来，从「我」的失向和现代物件来。写成了风景明信片 |
| 共用模板 | 三条都以「没有」收尾（没人回来扶／里头没有动静／烟囱上没有烟） | 同一个人换三种口音；署名互换照样成立，读者看不出是谁 |
| 只借零件 | 「烟囱上，没有烟」 | 那两样出自鲁迅书信里谈木刻构图的语境；抽词造句＝只借零件，没借眼睛 |
| 句法模板 | 「然而四面没有人」 | 为了像鲁迅而用「然而」起行（该作家的招牌句式） |
| 口头禅 | 「大约是…，也未必」连用三次 | 同一招用三次 |
| 写情绪词 | 「荒凉得让人心里空」 | 替读者下了结论，落差没碰出来 |
| 越过事实 | 「车过去几辆，都不响」 | 车不可能不响，为味道牺牲事实 |
| 词不对景 | 「路一直伸到城根」 | 现代大道没有城墙 |
| 细处靠猜 | 「一个穿黄，一个穿绿」（远景小人） | 图上只有指甲盖大，猜错就是编造 |
| 行数不合规 | 题记写成一整段、用分号断句 | 校验按 \n 数行 |
| 模具收尾 | 24 条里 15 条末句都是 5–8 字大白话，全以句号收 | 是我的检查器把所有人的末句逼成同一个形状；收尾要靠「末句类型」，不靠字数 |
| 同题材三连 | 一茶三张全自然小物、王小波三张全公路 | 比句式更容易露馅——读者先看出「又是这一类」，再看不出是谁 |
| 缺季语俗物 | 一茶只写溪水、水面 | 一茶的眼睛在俗物和穷日子里（垃圾桶、搪瓷盘、锁着的车），只写自然就只剩抒情 |
| 只旁观 | 灯「各照各的，倒也公平」 | 人没跟灯交过手，只是一句评价；加上「我站到灯底下」才成为互动 |
| 添道具 | 给村上版加「冰啤酒罐已经不冒汗了」 | 照片里没有啤酒和冰箱，为质感加东西就是编造 |
| 添别人 | 「谁在黑里摔了跤，它一概不负责」 | 画面里没有人；借别人受苦来加强反讽，越界 |
| 自嘲成瘾 | 「我这辈子，也没理清过什么。」（一茶写波洛克） | 拿画说自己；自嘲压过物，草木不见了。已改为「草也就这么长」 |
| 探头记录 | 「等她走过去了，那块橙红还得在那儿挂着呢。」（迟子建写罗斯科） | 画面准，但一个比喻都没有。已改为「像一块火，捂在谁的手心里」 |
| 借题 | 写《呐喊》：「我两手捂着脸……喊了多久」 | 画题已经替句子出了力；标题拿掉就不成立 |

> 旧称：「心眼」（2026-11-13 起统一改为「文心」；旧对话与旧实验记录里的「心眼」即此意）。
