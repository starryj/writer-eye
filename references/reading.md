# 读图规程（从图到文五步）

## 第 1 步：看形式

- 构图：对称 / 三分 / 中心 / 留白 / 满
- 景别：远景 / 全景 / 中景 / 近景 / 特写
- 光线：顺光 / 侧光 / 逆光 / 散射 / 硬光
- 色彩：冷暖、单色、高饱和、低饱和
- 时间与天气：晨 / 午 / 黄昏 / 夜；晴 / 阴 / 雨 / 雪 / 雾

## 第 2 步：看内容

- 主体是什么？占多大？
- 有没有人？人在做什么？几个人？关系如何？
- 环境给出了什么线索（招牌、路面、季节、植被、器物）？
- **画面里最不合常理的一处是什么？**（这一条经常就是题的来源）

## 第 3 步：列事实

写 3–5 条「只写看得见的」。规矩：能指认、能复核、不含推断。

- 好：「树桩锯断，断面发黑」「盒子里还有一点水」
- 坏：「他刚走不久」「她有点难过」

## 第 4 步：换眼睛

翻开这位作家的档案第 7 项，按他的观看顺序**重排**第 3 步的事实：
他会先看哪儿？再看哪儿？最后找什么？哪条事实在他眼里最重？

同时用第 5 项意象库、第 6 项温度与距离校准语气。

## 第 5 步：落笔

1. **主旨**（3–7 字）：这张照片的「眼」。可以是一个动作、一个物件、一个关系、一句没说完的话。
2. **题记**（2–3 行，≤99 字）：把这个眼撑开。不要复述主旨。
3. **自检**：见 rules.md。

## 附：主旨不是标题

- 标题是给检索用的（「夜巷」「初雪」），主旨是给读的人用的（「灯只照亮它自己那一段墙」→ 主旨「照亮自己」）。
- 主旨宁可偏斜一点，不要四平八稳。

## 附：题记的三种收法

- 收在一个小实物上
- 收在一个不肯说破的动作上
- 收在一句把前面的话推翻一半的话上

（三种不要连用同一种；同一张照片只用一次。）
